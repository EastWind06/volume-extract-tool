# 分卷压缩包分批解压工具

按顺序逐个解压 RAR / ZIP 分卷压缩包，**确认当前分卷数据已写入合并结果后，自动删除已处理完毕的分卷**，显著降低磁盘占用，无需预留双倍空间。

## 核心功能

- **逐卷回收**：解析 UnRAR 的分卷切换信号，只有确认下一卷开始读取、当前卷数据已落盘且无报错，才删除上一卷
- **预校验**：解压前可校验全部分卷完整性，缺失或损坏时拒绝删除任何文件
- **安全护栏**：只删同组已处理分卷，绝不删未处理分卷或成品；输出目录与分卷目录冲突时自动改到子目录
- **可控开关**：自动删除默认关闭，开启后必须勾选风险确认；另有“只解压不删”模式
- **全程日志**：每一步打印正在解压 partN、校验结果、是否删除 partN-1、剩余磁盘空间
- **内置引擎**：随包附带官方 UnRAR.exe，双击 exe 即可运行，无需安装 Python 或 WinRAR

## 支持的分卷命名

`xxx.part1.rar` / `xxx.part01.rar` / `xxx.rar.001` / `xxx.r00 + xxx.rar` / `xxx.zip.001` / `xxx.001` / `xxx.z01 + xxx.zip`

## 资源管理器右键菜单（无需预先启动软件）

在压缩包分卷文件或分卷文件夹上右键，即可看到 **用分卷解压工具打开**，点击后软件自动启动并填入选中路径。

**注意：右键菜单不会随 exe 自动生效**，别人下载 exe 后需要安装一次（菜单是写入 Windows 注册表的配置，不属于 exe 文件本身）。两种方式任选：

1. **最简单**：双击 exe 打开软件 → 点界面上的 **安装右键菜单** 按钮 → 弹窗确认即可（按钮会自动显示"安装/卸载/修复"，移动 exe 位置后会提示"修复"）。
2. **命令行**：执行 `分卷解压工具.exe --install-menu`（卸载用 `--uninstall-menu`）。

写入当前用户注册表，无需管理员权限；支持文件、文件夹、文件夹空白处三种右键。

## 下载与使用

从 [Releases](https://github.com/EastWind06/volume-extract-tool/releases/tag/v1.0) 下载 `volume-extract-tool-v1.0.exe`，双击运行即可。

演练自动删除前，请先把分卷复制到其他目录再操作——删除不可撤销。
